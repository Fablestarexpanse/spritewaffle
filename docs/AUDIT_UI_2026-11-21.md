# UI / layout / workflow audit — 2026-11-21

Walked the running app (v0.2.0) at 800 px and 1440 px wide, as a game developer: new jobs of each
type, item → base body → fit, animations, export, dialogs. Measured numbers are from the browser.
**Status:** P1 #1–4 and P2 #5–12 fixed the same day (see the end); P2 #13 done the same day; the P3 list is open.

## How the tool is used today (the workflows the UI has to carry)

1. **Character:** New → anchor → 8 facings → animations → export (.aseprite + atlas).
2. **Equipment (paper doll):** New item (front → back) → New base body (turnaround sheet) →
   on the base body: Make a variant… → pick the item → worn variant (8 facings) → animate → export.
3. **Animal:** New animal → turnaround sheet gives anchor + facings → animations → export.
4. **Effect:** New effect → one Effect tab (render, process, flipbook).
5. **Prop / sprite stack:** New prop → anchor → Sprite stack (views, slices, spin/build GIFs) → export.

## P3 — polish

Status 2026-11-26: the first three are done; the auto-reload note is still open.

- Anchor tab: the Description box shows only its placeholder on approved/imported jobs that have no stored description; say "(no description: imported)" instead.
- Sizes dialog: "used by 33 jobs: …" is one long run-on line; show the count with the list folded.
- Item jobs show Style / Prompts settings that change nothing after the item is drawn; hide them for item jobs once both views are approved.

## Fixed (2026-11-21, checked in the browser at 1440 and 800 px)

- #1 Job header is two wrapping rows (identity + actions, then settings); main column 1165 px at 1440, no horizontal scroll at 800.
- #2 Animal / base-body jobs: "Re-draw sheet" queues a new turnaround sheet (with a confirm); per-view Re-roll stays.
- #3 New is a dialog with a card per job kind and one line of help each.
- #4 Home offers every kind (character, base body, item, animal, effect, prop) and explains the equipment flow; item jobs have **Fit on…**.
- #5 Queue is a drawer opened from the header pill (running / waiting / failed counts); it opens itself when a task fails.
- #6 Item Facings: Front and Back cards.
- #7 Animations: each action lists the facings not rendered in one line and shows only real clips.
- #8 Approved anchor: Re-roll is a plain button with a confirm; the primary button is "Next: Facings →".
- #9 Make a variant… has three modes: Fit one of your items / Describe a change / From a picture.
- #10–12 Job list groups by kind; variants (fitted items, one-change variants) sit under their base job, labelled "wearing <item>" or "variant"; types read "base body", not `base_body`.
- Also fixed: the variant dialog read the removed New form's type to pick the tab after creating (would have thrown).

#13 done: 18 test/superseded jobs archived (jobs/_archive, reversible). Still open: the P3 list.
