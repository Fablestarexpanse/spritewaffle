# SpriteWaffle artwork

The supplied `SpriteWaffle_Full_Media_Kit.zip` contains the original Concept #5 artwork.
The archive SHA-256 is `65b2b2dc451e8aa7501974abbb0c60b6d24278bd90afdd445fa5536db8c84dc1`.
The 2048 px badge, original horizontal logo, and 1024 px app icon remain in the archive.

The app ships these supplied files under `spritewaffle/ui/static/brand/`.
